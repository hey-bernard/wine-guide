# 와인의 세계로 떠나는 첫걸음

와인 입문자를 위한 가이드 — 색과 스타일, 품종, 라벨 읽는 법, 테이스팅, 보관, 구매 가이드까지 7개 장과 부록으로 구성된 웹 문서입니다.

## 파일 구성

- `index.html` — 실제로 배포되는 페이지입니다. `<!DOCTYPE html>`, `<head>`, `<body>` 뼈대를 갖춘 완전한 HTML 문서입니다.
- `wine-guide.html` — 위 페이지의 본문 조각(원본 소스)입니다. Claude Artifact 퍼블리시 흐름에서 자동으로 `<head>`/`<body>` 뼈대를 씌워 렌더링하는 형식이라, `<!DOCTYPE>` 없이 `<title>`과 `<style>`부터 시작합니다. 내용을 다시 고칠 때는 이 파일을 기준으로 수정한 뒤, 앞뒤에 문서 뼈대를 씌워 `index.html`로 다시 내보냅니다.
- `bottles/` — 본문에 쓰인 실제 와인 라벨 사진, 포도 사진, 다이어그램용 이미지 등 모든 이미지 에셋.

## 배포

GitHub 저장소를 Vercel에 연결하면 `main` 브랜치에 푸시할 때마다 자동으로 재배포됩니다. 별도의 빌드 과정 없는 정적 HTML이라 빌드 커맨드는 비워 두면 됩니다.
